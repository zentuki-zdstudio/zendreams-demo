Noto source SHA-256: `bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d`. Existing installed fontTools 4.63.0 performed a lossless outline subset; no dependency was installed. Brotli/WOFF2 support was unavailable, so unchanged TTF delivery and the small TTF subset were selected. No raster compression or glyph approximation was used. The script reproduces glyphs/metrics; fontTools may update the generated font timestamp on rerun.

`star-girl-fonts.css` defines `Lexend` plus an app-only `proxima-nova` compatibility alias, both using the authorized Lexend file and an explicit unicode-range face for the two missing glyphs. This alias replaces the previous Typekit dependency; it is not a redistributed Adobe font. The two support glyphs are a disclosed local font composition, not an OS-dependent fallback. No other Lexend letter, numeral, multiplier or layout glyph changes family.

`tests/phase5-fonts.test.cjs` reads the fonts' real cmap tables and the actual currency symbol map, verifies every emitted currency/numeric glyph, checks the subset contains exactly its two declared characters, checks licenses and local dependency existence, and exercises font-gate rejection/acceptance. Browser verification remains necessary for cached Pixi text, Rules/Paytable, Replay, social, currencies, `25,000x` and small layouts.
